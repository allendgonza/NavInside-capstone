# Fase 2 — NavInside

Espacio para organizar la entrega de avance del Proyecto APT. Completar la guía oficial y adjuntar evidencias verificables del proyecto.

## Contenido de la guía

1. **Resumen de avance del Proyecto APT**
   - Avances y objetivos específicos cumplidos.
   - Objetivos y metodología, solo si hubo ajustes.
   - Evidencias y justificación de cómo demuestran el desarrollo y la calidad del proyecto.

2. **Monitoreo del plan de trabajo**
   - Competencia o unidad, actividad, recursos, duración y responsable.
   - Observaciones, estado de avance y ajustes.
   - Estados permitidos en la guía: en curso, con retraso, no iniciado, completado o ajustada.

3. **Ajustes a partir del monitoreo**
   - Facilitadores y dificultades, con acciones para abordarlas.
   - Actividades ajustadas o eliminadas y su justificación.
   - Actividades no iniciadas o retrasadas y estrategia para avanzar.

4. **Registro de evidencias**
   - Adjuntar evidencias que respalden el avance y revisar que no expongan credenciales.
   - Registrar el aporte de cada integrante.
